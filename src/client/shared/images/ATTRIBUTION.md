# Counter-Strike chicken

`cs2-chicken.png` is the Catalana chicken render from [CS2Locker’s Counter-Strike 2 pets page](https://cs2locker.com/pets), downloaded unchanged on November 16, 2026 from [the original PNG](https://cs2locker.com/pet-assets/chicken-catalana.png).

The source describes the render as made from the game's own models. Counter-Strike game artwork belongs to Valve; rendering credit belongs to CS2Locker. This asset is separate from DONATECONTROL's original code and styling. Its inclusion does not imply Valve or CS2Locker endorsement.

The image is bundled locally so both OBS browser sources work without fetching third-party artwork at runtime.
