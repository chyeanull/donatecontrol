# MustacheRider artwork

The project owner supplied these SVGs in the original `mustach/` folder. They are kept unchanged and bundled into the graphics by Vite. PNG design references are in `docs/theme-references/mustacherider/`.

Both SVGs use the same 769.47 × 277.43 canvas. Keep their alignment and aspect ratio. Render the bun first, then reveal the mustard with a horizontal clip based on its visible path bounds. Do not stretch the mustard to represent progress. Cash labels are separate dynamic SVG text, using Rubik Spray Paint loaded from Google Fonts.
